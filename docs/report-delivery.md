# Deliver a finalized client report

1. Open **Reports** in the operator console. Open an audit report or follow the monthly report to its cycle.
2. Review the findings, recorded work, and evidence limitations. Finalize the report after review.
3. Select **Download finalized report**. Open the HTML file locally and use the browser’s print dialog to save it as a PDF if needed. Review the exported file and verify the intended recipient before sending it through your approved delivery channel.

The download uses the active workspace and the same read permissions as the report pages. A draft cannot be downloaded. The monthly file uses the finalized snapshot, so subsequent work in the console does not change the report. The document includes selected findings, work status, and limitations. It omits raw captures, internal record references, and private operational fields.

Downloading creates a local customer document. Store and share it through approved channels. The operator sends the file directly. The console URL is for signed-in operators.
